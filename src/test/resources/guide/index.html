Introduction

This guide is being maintained through the OpenJDK Developers' Guide Project.

Author, Committer, Reviewer

OpenJDK has three roles for contributors.

Becoming a Committer

To become a Committer you need to have made at least eight significant contributions to the project.

Working With Pull Requests

Backporting

Backporting a fix means applying it to an older release. A backport pull request references the original commit.

Withdrawing a change

Close the pull request and explain why.
